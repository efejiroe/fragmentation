# SEL Outpatient Fragmentation Analysis

This repository contains data, analysis tools, and strategic documentation for the South East London (SEL) Integrated Care System's review of outpatient care fragmentation. The project aims to improve system sustainability and patient outcomes by identifying and reducing unnecessary complexity in clinical pathways.

## Project Overview

The core of this work is the assessment of how patients navigate the healthcare system, specifically focusing on those seeing multiple specialists across different provider sites. The project uses population health data to quantify fragmentation and propose interventions that shift care toward more continuous, patient-centred models.

### Key Objectives
* **Quantify Fragmentation**: Calculate validated indices to measure care dispersion across the SEL population.
* **Identify High-Risk Cohorts**: Focus on adults aged over 65 and adults under 65 with three or more long-term conditions (LTCs).
* **System Sustainability**: Target a reduction in outpatient appointments to deliver significant financial savings and reduce backlogs.
* **Clinical Intervention**: Use data-driven insights to pilot multidisciplinary team (MDT) reviews and "lead specialty" approaches.

## Methodology and Metrics

The analysis primarily utilizes the **Fragmentation of Care Index (FCI)** as a baseline, with the **Sequential Continuity Index (SCI)** recommended as a secondary measure to identify process failures like clinical "ping-pong".

### Calculated Indices
| Index | Description | Application |
| :--- | :--- | :--- |
| **FCI** | Measures dispersion based on total visits and number of distinct providers. | Primary baseline for SEL population analysis. |
| **SCI** | Assesses whether a visit is followed by a visit to the same provider. | Identifying broken clinical pathways and loops. |
| **UPC** | Ratio of visits to the most frequent provider over total visits. | Widely used in GP research to predict admission risks. |
| **Bice-Boxerman** | Weights both frequency and dispersion of visits. | Academic "gold standard" for statistical reliability. |

## Targeted Opportunities
The project identifies several areas for transformation to reduce fragmentation:
1.  **Improving Referral Pathways**: Standardising triage and using specialist advice to prevent unnecessary hospital visits.
2.  **Streamlining Appointments**: Implementing digital scheduling, PIFU (Patient Initiated Follow-Up), and reducing DNAs.
3.  **Community Integration**: Maximising primary care options and utilizing community-based group consultations.
4.  **Population Health**: Using data to address health inequalities (Core20PLUS5) through targeted prevention.
